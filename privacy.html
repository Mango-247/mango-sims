Privacy policy

Mango Sims Uploader. Last updated November 8, 2026.

Mango Sims Uploader is a personal tool that uploads videos to the Mango Sims YouTube channel. Only the channel owner uses it, and only with the owner's own Google account.

What it accesses

With the owner's permission, the tool uses the YouTube Data API to:

  • upload videos to the owner's channel
  • read the status and view counts of the owner's own videos

It does not read or collect data about viewers, subscribers or any other YouTube user.

Storage and sharing

The sign-in token Google issues is stored only on the owner's computer. No data is sent to any server run by this tool, and nothing is sold or shared with third parties.

Revoking access

Access can be removed at any time from the Google account's third-party connections page.

YouTube and Google

This tool uses YouTube API Services. Use of YouTube is covered by the YouTube Terms of Service, and Google's handling of data is covered by the Google Privacy Policy.

Contact

Questions can be sent through the project's GitHub page.
